# 数据转换与置信度规则

按以下级别处理来源字段：

- **Observed（直接观察）**：直接来自表格单元格、标签、文件名或关联关系清晰的题注；
- **Derived（规范化派生）**：只调整格式而不改变含义，例如清理空白或创建稳定 ID；
- **Inferred（推断）**：看似合理但来源未明确表达。用户确认前不得写入可执行字段；
- **Missing（缺失）**：必要信息不存在。写入报告并保持未解决；
- **Conflicting（冲突）**：不同来源互相矛盾。在报告中保留两侧证据并请用户选择。

只有在来源权利允许时才裁剪或提取缩略图，并记录来源页码或行。除非文档明确说明人物是比例参照，否则不得根据带人物的缩略图推断缩放或真实尺寸。

最终报告应列出来源标识、原始行数、导入数量、跳过数量、警告和未解决项。不得包含密钥、凭据或与资产转换无关的文档正文。

## 建议处理顺序

1. 保留原始文本和来源位置；
2. 规范空白、大小写和稳定 ID；
3. 把明确的模型名写入 `provider_metadata.model_name`；
4. 将类别转换为 collection，将检索词转换为 tag；
5. 仅在证据明确时填写建议缩放；
   参考半径、参考高度同样只填写有来源或经用户确认的尺寸，并统一为米；冠幅直径仅在明确指的是圆形参考范围时才能除以 2 得到半径。高度不得与地形高程混用。
6. 对每个未确认字段生成报告项；
7. 在用户确认后构建 `.vfa`。

不要让 Agent 为了提高“导入成功率”而自动补齐关键缺失字段。一个明确暴露的不完整资产记录，比一个无法追溯的错误映射更安全。
