# 策略参数与角色的展示关联

策略 v2 的 `generation_parameters` 每项可选声明 `visible_for_roles`，由策略作者持有，
不在 Studio、SystemHost 或实时面板维护参数键/策略 ID 的关联表。该能力补充 ADR-0004
公开参数展示契约。展示声明不决定算法行为；角色感知构图由策略按 ADR-0004 自行处理，
Core 始终后过滤关闭角色。

```yaml
- key: spacing_m
  visible_for_roles: [primary_structure]
  value_type: number
  default: 4
  min: 1
  max: 20
  step: 0.5
  group: quick
  display_name: 植被间距
  effect: 控制主体植被点位的间距。
```

## 语义

- 未声明：全局参数，始终展示。
- 声明非空角色数组：任一关联角色启用则展示，全部关闭则隐藏。角色缺省为启用。
- Domain 校验数组不重复、引用本策略已有角色；SystemHost 原样输出类型化角色列表。
- 展示过滤仅影响调参控件与效果摘要，不删除草稿、Profile 预设或执行参数。重新启用角色
  后恢复原值。生成器可根据角色开关推导内部有效值，但应用不改写默认值、预设或请求。
- 不解析参数键中的角色名，不通过描述文本推断绑定，不引入条件表达式引擎。

## 维护策略

层次生态群落 2.2.0 的铺底覆盖率与间距只关联铺底角色，主景比例与间距只关联主景；
宏观斑块尺度保留为全局参数。关闭铺底后主景以整个 Region 为覆盖基准，因此无需继续
显示铺底覆盖率，也不将内部有效 100% 写回 Profile。草坪点景组团的主体草坪间距只关联主体草坪，
组团密度与数量关联三个点景角色。主景出现概率也改变周边点位环绕尺度，因此仍关联
全部点景角色，不因关闭中心主景就隐藏。没有公开参数的策略无需新增声明。

VFS Author 模板和作者说明同步该字段，`.vfs` 交换与策略快照保留原声明。展示资料更新
按正常包 hash/信任规则处理，不自动改写已安装的策略或旧 Profile。
