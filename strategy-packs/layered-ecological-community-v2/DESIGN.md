# 层次生态群落 2.2.2 设计

状态：保留既有构图规则，性能优化待真实 DTS 视觉验收

## 1. 设计目标

用最少的空间职责表达生态群落的主要关系：地表基质形成广泛承接，主景结构进入其中的高值
核心。Role 不代表具体植物种类，同一 Role 可以映射多种在空间关系上等价、尺度大致相近的资产。

## 2. 密度场

算法在世界 XY 坐标上构造一张确定性的多尺度 fBM 宏观场，并加入低频域扭曲，避免斑块沿规则
网格展开。连续场按宏观斑块尺度的 `1/16` 转换为世界坐标对齐的密度纹理；纹理惰性计算并
缓存 texel，阈值统计、地表候选与主景候选通过平滑双线性插值复用同一份数据。它不按 Region
完整预分配位图，因此大包围盒或细长 Region 不会无条件占用整幅纹理内存，相邻采样也不会在
分块边缘产生接缝。每个 Region 根据目标覆盖率计算自身场值分位数：

- 启用铺底时，地表阈值由 `groundcover_coverage_percent` 决定；主景阈值由地表覆盖率
  与 `focal_core_ratio_percent` 共同决定，不越出地表支撑区。
- 关闭铺底时，内部有效地表覆盖率为 100%，主景阈值只由 `focal_core_ratio_percent`
  决定，以整个 Region 为覆盖基准，不读取已隐藏的铺底覆盖率或间距。

分位数统计使用确定性的规则网格，2.2.2 将单 Region 的统计网格预算从约 24,000 降为
约 2,048 个包围盒样本。实际网格还受行列向上取整和至少四行四列约束，预算并非硬上限。
这只降低覆盖率阈值估算成本，不限制最终候选点数量。阈值估计变化可能改变少量支撑区
边缘点，固定新包、区域、参数、种子和角色开关仍可复现，不承诺跨策略版本逐点相同。

噪波计算对每个八度的四个格点值建立 LRU 单元缓存，以整数格点位置和完整种子为键，
最多保留 65,536 个单元。区域和角色可以复用相同噪波单元，不混用种子，不改变原有插值
运算顺序。缓存属于策略 Worker 进程内存，进程结束即释放，不写项目或用户库；无需
第三方依赖、Core 缓存或新执行协议。纹理分辨率和候选生成密度保持原值。

阈值只确定允许种植的空间支撑区。点位在各自支撑区内按抖动六角网格生成，再由角色独立的
高频场调整接受概率，使同一宏观斑块内部仍有轻微疏密变化。

## 3. 角色感知构图

Worker context 只传入目标无关的 `excluded_role_keys`，不传入 Profile、Catalog 或资产
数据。策略持有角色开关后的空间规则：关闭铺底会改变主景覆盖基准，关闭主景则只跳过
主景计算。共享宏观纹理和角色独立随机流保持稳定；相同完整输入（包含角色开关）可复现，
但不同开关组合不要求逐点相同。因此本版本不声明 `filter_equivalent`。Core 无论策略是否
处理开关，都在定版前执行后过滤，保证关闭角色不进入最终结果，见 ADR-0004。

`visible_for_roles` 只决定控件展示；铺底参数被隐藏后仍完整保存。内部有效 100% 只在
算法内计算，不写回参数对象、Profile 或执行命令，也不扩大公开参数的 5–98 输入范围。

## 4. 边界索引

每个 Region 在生成开始时会将外环和孔洞预构建为精确的 Y 轴边索引，阈值采样、地表候选和
主景候选共同复用。点在面内判断仍采用相同的射线交叉规则，索引只跳过不可能与当前高度相交
的边，不简化原始轮廓，也不使用近似栅格掩膜，因此不会以边界精度换取性能。

## 5. 参数语义

覆盖率是 Region 面积上的场值分位目标，不是最终资产冠幅的真实覆盖率。真实视觉密度还会受
点位间距、Profile 缩放和资产自身尺寸影响。主景支撑区占整个 Region 的目标比例为：

```text
铺底启用：groundcover_coverage_percent * focal_core_ratio_percent / 100
铺底关闭：focal_core_ratio_percent
```

例如默认 `85 / 55` 在启用铺底时对应约 `46.75%` 的主景支撑面积，关闭铺底时对应约
`55%`。分位数按采样估计，不承诺最终模型占地精确符合此比例。

## 6. 边界与非目标

策略包不读取 Catalog、Profile 或资产尺寸，也不承诺具体模型冠幅互不重叠。建议同一
`focal_structure` Profile 候选保持大致相近的构图尺度；若未来确实出现另一类独立空间关系，
再以新 Role 或新策略表达，而不是把物种分类直接写进 Role。

本版本不修改 PointSet v2 或 Plant Run 编排。相同坐标的点仍使用原旋转规则；阈值采样
预算变化通过新的不可变策略版本独立安装和验证，不覆盖旧包或静默升级已有 Profile。
