# VerdFlow Apps

App 是产品进程、传输或交互入口，不复制领域算法、SQL 或外部平台协议。

- `core-host`：单项目执行组合根。
- `system-host`：用户库、机器配置与多项目线程生命周期。
- `local-api`：loopback HTTP 映射。
- `dts-live-connector`：Explorer WebUI 同源认证与回调传输。
- `dts-live-webui`：实时多面种植、选区管理和参数示例侧板。
- `studio-service`：Studio 可丢弃只读视窗投影。
- `studio`：Vue 工作台与资源配置。
- `studio-electron-probe`：桌面 PlatformBridge 和运行时托管。
- `cli`：命令行与诊断入口。

各模块公共入口和维护说明见 [模块索引](../packages/README.md)。
