# ADR-0018：推荐资源清单与快捷导入

状态：Accepted。

1.0.2 起由 [ADR-0020](0020-plan-import-dependencies.md) 扩展方案推荐、导入确认与可选来源资产库；旧版清单保持兼容。

## 决策

- 资源仓库维护 `collections/starter.json`，只选择资源 ID 与推荐/固定版本。构建从正式记录
  生成 `starter-resources.json`，携带下载、大小、摘要、包身份和清单 revision，避免重复维护信息。
- 新手引导只在用户主动打开时读取清单，明确点击后批量导入 VFA/VFS；不是自动信任或静默安装。
  清单可以独立部署，调整资源不需要发布新客户端。
- Studio 只做展示，通过认证的 Local API 调用 SystemHost。SystemHost 独立线程下载和校验，
  复用现有包解析与 Library 导入；Core、策略和交换格式不承担资源中心能力。
- 固定 HTTPS 清单、同仓库固定 Release 附件与受控 GitHub CDN；限制大小和下载时长，校验摘要及
  包身份。摘要不是签名，也不是对策略代码安全性的证明。
- 相同内容重复导入保持幂等；资产冲突不覆盖本地内容。失败保留其他成功项，可重试或取消；
  完成和取消回收临时目录，宿主退出停止任务，页面卸载清理轮询和迟到响应。
- 新策略仍需用户确认信任，已撤销状态不因导入恢复。PAK 保持外部链接，方案包暂不纳入快捷导入。
- 资源中心不可用不影响本地运行和文件导入。此能力不等同于社区账户、自动资源升级或执行市场代码。

## 验证

检查鉴权、下载与包校验、冲突保护、幂等、信任状态、部分失败、取消清理和多尺寸 UI；
公开资源的端到端验证使用隔离 Library，不改动用户已有资源。
