# ADR-0005：资产目录、自包含搭配与运行快照

状态：Accepted。适用版本：1.0.0。

## 背景

资产库是便利索引，而不是目标平台实际资源存在性的证明。项目临时资产与通用资产
需要独立维护，但一次搭配应能够选择多个来源且不被重复 ID 误覆盖。

## 决策

- Catalog 是特定 target/provider 下的可变索引；generation 用于并发编辑，不是版本树。
- Profile 自包含候选的目标引用、名称快照、权重、缩放、角色开关和可选参数，不依赖
  来源库继续存在才能执行；可选来源链接用于提示、展示和用户确认后的同步。
- 跨库候选身份由目标、Provider、库和原始资产 ID 的结构派生；保留原始库内 ID。
  目标 locator 不因内部候选命名而修改，App 不自行拼接或拆解业务身份。
- 一次搭配只能属于兼容的目标与 Provider；不同来源指向相同目标时不静默合并权重。
- 仅本次使用的完整搭配是输入值，不保存隐藏的临时 Catalog 或 Profile。
- 切换浏览库只重载浏览区域，保留已经选中的候选、权重、缩放和角色状态。
- 执行冻结选中候选的稀疏事实及分配结果，后续库或方案编辑不改变该次运行。
- 参考半径和高度是可选展示元数据，不是实际几何、碰撞界限或策略输入；缺失不得阻塞。

## 影响与限制

来源库删除可以使缩略图不可用，但不能让完整目标引用失效。`.vfp` 不承诺携带缩略图。
来源漂移不得静默覆盖冻结值。Catalog 中有名称不代表目标平台可加载该模型；实际资源
检查由相应 Provider 能力决定，不能用内部 ID 改名解决目标定位歧义。

## 验证要求

测试跨库同 ID、不同模型、来源移除、显式同步、候选权重与缩放、Profile 往返、完整
草稿执行及旧快照不变；确认策略和采样链路不感知来源库数量。
