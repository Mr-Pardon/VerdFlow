# ADR-0014：示例与敏感数据

状态：Accepted。适用版本：1.0.0。

## 背景

可复现的工程需要代码、契约和测试，但不应依赖使用者的工程原件、账户、机器配置或
现场验证资料。示例应能在不同机器上安全复现。

## 决策

- 测试使用合成模型、几何、目标名称和占位凭据；错误输入明确用于验证拒绝行为。
- 用户 Library、项目、输出、凭据、运行日志和缓存不作为项目源码或测试依赖。
- 提交数据、图片或日志前检查使用权，以及其中的路径、地理位置、业务标识和元数据。
- 文档只记录设计和可复现的验证要求，不通过附带用户原件来证明规模与性能。
- 发现已提交的凭据时应先撤销或轮换；删除当前文件不能清除既有提交里的内容。
- 示例、依赖和制品分别检查内容，模式扫描不代替图片、元数据和权属审查。
- 扫描与故障报告尽量只输出规则和位置，避免在报告中再次复制凭据和其他敏感原文。

## 影响与限制

匿名化要保留测试和契约的含义，不能为了删路径而破坏安全失败测试，也不能把真实失败
改写成验证成功。零模式命中不等于所有内容都安全、合法或适合再分发。

## 验证要求

独立安装依赖后运行测试和构建；检查文档链接、示例来源和运行资源闭包。
测试不得访问使用者的常用项目或向真实目标场景发送修改命令。
