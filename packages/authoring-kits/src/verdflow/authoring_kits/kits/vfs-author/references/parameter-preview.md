# 参数示例

在 `strategy.yaml` 中可选增加单一样本，用原生成器展示当前公开参数和角色开关的变化。
Studio 不持有样本或策略专属算法，不需要图片、HTML、脚本、远程地址或新生成器入口。
Studio 与实时 WebUI 共用同一声明和展示能力；不需要为不同入口另做预览代码或适配包。

```yaml
extensions:
  parameter_preview:
    version: '1'
    display_name: 道路绿带
    fixed_seed: 17
    boundary_xy: [[0, -3], [160, -3], [160, 3], [0, 3]]
```

## 样本设计

- 每个策略一个无内洞的简单边界，本地坐标单位为米；不能统一套矩形，也不要伪装成
  真实用户项目。行道树应是能体现排布的狭长绿带，群落应能容纳多处斑块，草坪点景
  应有足够内部空间容纳组团，并通过圆弧或凹边界说明收边效果。
- 弧线可用有限折线近似。名称最多 80 字，顶点 3 至 256，单轴跨度不超过 1000 米，
  坐标绝对值不超过 10000，面积 0.01 至 50000 平方米；避免过密的边界或过大样本。
- `fixed_seed` 为 0 至 2147483647 整数，不在面板提供随机操作。选一个有代表性的固定
  结果，使用户只比较参数变化，不被随机变化干扰。实际种植的种子不受示例影响。
- 主体间距在最小值时也要测试规模；不能通过偷偷缩放坐标、抽稀点位、改写公共参数
  或使用未经等价验证的近似算法来宣称实时预览。

## 执行与验证

上下文仍调用 `generator.py:generate(context)`，包含原策略、固定种子、当前公开参数、
`excluded_role_keys` 和一个 ID 为 `strategy_example` 的标准 Region，所有 Z 为 0。
不读取 Profile、Catalog 或资产信息。策略拥有关闭角色后的构图，宿主最终过滤关闭角色。

## 参考范围不属于策略

Studio 可将用户搭配中的参考半径、权重和缩放叠加到示例点位。候选与随机缩放由通用
Resolver 解析，参考圆由 Studio 计算和绘制；本功能不增加策略作者工作。不要读取资产库、
返回半径、实现画圆或新增专用生成入口。正常点位 ID 沿用既有稳定、非空、唯一的契约；
宿主仅把已有 ID 传给展示层，不要求策略增加新输出字段。
若 ID 超出临时搭配解析的 256 字预算，仅回退普通点位示例，不改变正式生成契约。

换植被、权重、缩放或参考半径不会重跑策略；角色开关及空间参数仍可重新生成。缺少半径
保持普通角色符号。参考范围并非真实冠幅、碰撞或防越界承诺，不应据此在生成器中自动
裁剪、排斥或改变间距。样本与说明声明均为可选，不提供也不影响正式种植。

示例只返回二维展示投影，不产生项目点位，不做高程或导出。当前预算为 100000 点、
8 MiB 输出、30 秒执行；超限仅禁用本次示例，不改变正式生成能力。允许零点示例。

对默认值、公开参数极值和角色开关组合，比较完整生成与示例投影的点位顺序、XY 和角色；
验证改参再恢复得到相同结果。若预览较慢，优先缩小合适的样本或改进原算法，不在 Studio
加入策略特殊分支。缓存不是必要接口；未来若提供，必须由策略持有并验证逐点等价。

声明随策略文档进入正常包 hash；修改后应升级策略版本并重新导入、显式信任。没有声明
的旧包仍可使用。可选声明不合法时 UI 不展示示例，不应破坏正式种植。
