# 策略植被用途展示

状态：Experimental；仅 App 展示，不改变执行契约。

## 边界

角色描述空间分布中的植被分工，不代表固定物种。界面使用“植被用途”帮助用户挑选素材，
执行仍使用原有 `role_key`、`required`、`assignment_policy` 和 Profile assignments。
推荐植被、组名、说明和构图示意不参与点位生成、资产校验、权重、缩放或启用判断。
静态示意不是当前选区预览，也不承诺资产实际尺寸或覆盖率。

角色名称和说明只来自策略包的 `roles`。`SystemHost.get_strategy()` 在已经校验策略包
身份的查询结果上，通用解析包内可选展示声明为 `StrategyRoleInfo.guide`，不另定义角色
名称、阈值、构图或推荐内容。LibraryStore 保存原包；查询不会改写包、信任、Profile
或项目输入。DTS Live 通过既有 configuration options 得到同一只读投影。

Studio 和 DTS Live 共用 `@verdflow/role-guide-ui` 的用途卡片与构图示意组件，组件不按
策略 ID 分支，不发请求，不保存配置。配置行为仍由对应应用持有。

## 资料来源

唯一来源是策略文档可选的 `extensions.role_presentation`。内容由策略作者维护，随
策略导入、`.vfs` 导出和项目策略快照一同保存。没有声明或声明无效时，仅保留基本角色
展示，不阻断策略执行；不存在应用层按 ID、版本或 hash 查找的补充资料表。

新增策略只提供相同声明即可，不需要修改 Studio、实时面板、SystemHost 或 Core。
通用渲染器可以拥有有限符号与配色能力，但不能拥有具体策略的图、坐标、名称或阈值。
查询解析器只验证展示结构与限制，不解释算法。生成规则及其参数归策略，资产选择、
权重与缩放归 Profile/本次映射，图示不得反向影响这些执行契约。

修改展示内容也改变包 hash，应作为正常策略包更新处理；不能覆盖已安装包或复用旧
信任。当前三个维护包使用补丁版承载资料，既有项目快照与 Profile 不自动升级。

## 可选声明

```yaml
extensions:
  role_presentation:
    version: "1"
    roles:
      ground:
        suggested_assets: [花草, 地被, 矮灌木]
        note: 可选同一尺度的一种或多种素材。
    groups:
      - id: base
        name: 底层覆盖
        description: 低矮植被铺底。
        role_keys: [ground]
        diagram:
          - {role_key: ground, kind: groundcover, x: 50, y: 30, size: 10}
```

展示声明必须完整覆盖原策略的角色集合，每个角色恰好属于一个组。组可设置非负整数
`order`；默认按组数组顺序排列，组内沿用策略文档角色顺序。角色名称与说明由原有
`roles` 唯一提供；`suggested_assets`、`note` 与 `diagram` 可省略，不在扩展中重复定义。

示意使用 `100 × 62` 的归一化画幅：`area` 为 3 至 32 个二维顶点组成的面，
`tree`、`shrub`、`groundcover` 为内置 Lucide 符号。坐标限定在画幅内，符号尺寸不超过
24；每组最多 128 个标记、总组数最多 32、每个角色最多 8 项推荐，文本不超过 500 字符。
仅允许引用本策略存在的角色，不接受 HTML、脚本、自定义 SVG 或远程资源。

输出 DTO 将组顺序、名称、说明、推荐和示意展开到各角色的 `guide` 中，未提供资料时
为 `null`。此字段是 App 查询投影，不属于 Core 的 Strategy/Binding/Profile 契约。

## 首轮表达

- 层次生态群落：铺底植被、主景植被，不限定生物分类。
- 草坪点景组团：草坪覆盖与点景组团两组；关闭中心主景只筛掉对应点位，不重新构图。
- 通用行道树：沿线乔木先列，其余按窄、中等宽度、宽绿带分组；宽度模式由现有算法
  自动选择，说明中的阈值是默认值，不是界面重新定义的规则。

## 验证

后端验证作者可选声明、无效资料回退、角色执行字段保持不变，以及 `.vfs` 往返后资料
完整。已安装包仍保持原身份，新展示资料不会通过应用注册表补到旧包上。
前端验证用途分组、颜色、卡片切换、声明式示意、启用、既有植被选择、权重与缩放。
浏览器检查使用受控资料与模拟 API，不触发真实 DTS 种植或改写用户库。
