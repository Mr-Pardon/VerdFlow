# ADR-0006：种植方案与统一执行主链

状态：Accepted。适用版本：1.0.0。

## 背景

用户按用途复用已经调好的配置，比每次理解策略、资产和参数更直接。界面便捷入口
不能形成另一套生成、高程或输出算法。

## 决策

- 用户侧统一管理种植方案，底层复用自包含 Profile，不增加平行方案实体与版本树。
- 方案保存策略版本基线、搭配和公开效果参数；执行前按
  [ADR-0016](0016-compatible-planting-plans.md) 解析兼容版本，补齐默认值并冻结实际输入。
- 预设方案和手动配置只是两种 UI 入口，最终提交相同执行命令。
- 微调只改变运行草稿；保存时明确选择更新原方案或另存副本，保留并发校验。
- 选区、随机种子、高程、最终偏移和任务状态不作为可复用方案的一部分。
- Plant Run 编排规范区域、生成、分配、高程与输出，恢复使用已冻结输入，不重新读取
  当前 Library 去改变正在执行或已有结果。
- 提交时冻结完整 Profile 快照及实际执行的精确策略版本和 hash；运行中的任务不随
  方案后续修改、删除或策略升级而改变。
- 同一固定场景的多批次保留规范区域与点位事实；保存批次不必立即采样或生成 XML。
- 最终输出按当前保留范围和筛选结果生成独立文件记录；删除一个输出不能隐式删除
  项目区域或种植结果。

## 影响与限制

可追溯执行记录不等于用户可任意回到所有历史场景版本。任务持久化也不表示实时
会话和目标平台副作用都能跨重启恢复。不同输入路线必须明确各自的恢复边界。
方案卡片和缩略图是可选展示，不成为执行门禁。

## 验证要求

测试两种入口等价、默认参数重置、临时调整不回写、更新与另存、活动任务恢复、
多批次选择，以及 XML 文件生命周期与项目事实相互独立。
