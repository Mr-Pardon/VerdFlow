# ADR-0021：有界实时输入、合法内环和数据错误

状态：Accepted。随 1.1.0 交付。

## 决策

- 实时路径用于有界交互式种植；文件及解压数据限 128 MiB，单次与累计规范选区限
  200000 顶点，包含内环。草稿仍限 30 MiB，请求体仍限 32 MiB。
- 合法孔洞属于正常面表达，贯通解析、标准多环区域、场景展示、命中与导出。
  不静默填洞、跳过无效面、修复、切分或重投影。无效几何与容量超限分别提示。
- 首次显示创建对象，后续使用 show/hide；移除、清空及销毁仅删除本会话对象。
  ID 和显示状态不复制执行几何，隐藏面不参与点击。
- 数据错误携带稳定错误码和原因、位置、处理建议；体积、顶点、配套文件、几何、
  高程覆盖、NoData、波段及 Worker 失败分别处理。原始异常仅保留在本地诊断中。
- 同步错误由 SystemHost 转为公共数据错误，HTTP 层不解析文件；异步错误沿 Worker、
  Job 和既有查询展示。失败保留项目，不伪造结果或自动重导回执未知的 XML。
- 超限引导工作台 SHP＋TIF，用户仍负责坐标对齐。工作台不是无限数据或自动修复承诺，
  实时路径不扩展为大数据执行队列。
- 操作反馈可以手动关闭，仅隐藏展示，不删除失败记录。新操作或新错误重新提示，
  不因常规轮询反复弹出同一条已关闭消息。

## 验证边界

覆盖合成内环往返、标准区域、显隐和清理、累计限额及错误传播。
实际目标平台的容量、显隐延迟与最终导入仍需现场验证；真实私有数据不进入公共测试。
