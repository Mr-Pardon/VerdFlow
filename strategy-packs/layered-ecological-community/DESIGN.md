# 层次生态群落策略设计

状态：Accepted baseline

基准版本：`layered_ecological_community@1.0.0`

## 1. 决策摘要

首版作为一个独立复合策略包实现，不在 Core 引入通用多策略调度层。策略不先把
Region 切成互斥子面，而是对四个植被 Role 分别生成连续、相关、多尺度的密度场，
再在同一 XY 空间叠加满足各自间距的点位。

已通过视觉验证并固化的关键效果：

- 上层主导植物的高密区可形成连续冠幅肌理。
- 上层主导植物密度会沿连续场逐渐减弱，不出现人工切面边界。
- 上层主导植物低值区仍保留地表覆盖，形成疏而不空的过渡。
- 不通过随机删点、圆形聚落或显式留白多边形制造构图。

## 2. 为什么连续密度场有效

每个 Region 根据运行 seed 和稳定 `region_id` 派生一个共享低频场及各 Role 的独立场。
连续场只提供空间倾向，不产生封闭斑块；因此两个位置越接近，密度变化通常越平滑。

最终外观来自四类约束的共同作用：

1. 内部固定的 `cluster_scale=1.25` 决定疏密起伏的空间尺度；当前不向用户暴露。
2. `canopy_field_contrast` 拉开上层主导植物的高值区与低值区。
3. `canopy_spacing_scale` 和 Role 最小间距保证高值区有秩序而非堆叠。
4. `layer_blend` 让不同高度层共享部分趋势，同时保留独立细节。

若只提高上层主导植物数量而不调整场对比，结果会退化为全域均匀铺满；若只提高对比而点位
过少，又会退化为彼此断开的局部聚落。`1.0.0` 默认参数是这两者的已验证平衡点。

## 3. Role 契约

| Role Key | 空间职责 | 基准生成特征 |
| --- | --- | --- |
| `canopy_anchor` | 上层主导植物 | 大尺度高对比场，较大最小间距。 |
| `medium_shrub_structure` | 中层结构植物 | 中尺度起伏，较低密度形成节奏。 |
| `herbaceous_companion` | 下层伴生植物 | 自身密度场与附近上层主导植物影响共同决定。 |
| `low_shrub_matrix` | 地表覆盖植物 | 较高场底值和较细尺度，保持连续覆盖。 |

四个 Role 的 `assignment_policy` 都是 `weighted_pool`。Role 只表达构图职责；Profile 负责具体资产、
候选权重和缩放。只更换 Profile 或 `assignment_random_seed` 不应改变空间点位。

## 4. 生成流程

每个 Region 独立执行：

1. 解析一个外环和零个或多个孔洞环。
2. 根据 Region 面积、Role 基准间距和密度倍率计算目标数量。
3. 在 Region 内确定性生成候选点。
4. 用共享场与 Role 独立场对候选点排序。
5. 依次接受满足 Role 最小间距的高分点。
6. 写入目标无关的 Role、未采样位置和确定性旋转。

候选排序会保留连续场的高低趋势；最小间距网格只在同一 Role 内作用，不阻止不同高度层
在相同 XY 范围叠加。

## 5. 参数边界

`strategy.yaml` 的顶层 `generation_parameters` 是公开参数契约，统一声明默认值、范围、步长、
展示分组和结果导向说明。Studio 与 DTS Live WebUI 可以共用该契约渲染控件，不识别具体参数键。

运行时覆盖通过：

```text
generation_args.strategy_parameters
```

进入生成器。生成器拒绝未知参数、非数值、非有限值和超出契约范围的值，不依赖界面前置校验。

## 6. 确定性

一份结果由以下输入共同决定：

- 规范 Region 几何及稳定 `region_id`。
- 精确策略包哈希。
- 规范化运行参数。
- Plant Run `seed`。

Region 在生成前按 ID 排序，所有子随机流从主 seed、Region ID、Role 和算法阶段派生。
实现不依赖 Python hash 随机化、无序字典遍历或输入 Region 顺序。

## 7. 职责与非目标

策略包负责：

- Region 内空间场与 Role 点位。
- 参数闭合校验。
- 目标无关 PointSet v2 输出。

策略包不负责：

- 资产选择、权重与缩放。
- Blender 或 DTS 高程采样。
- XML 或其他目标格式导出。
- 持久化密度场或可编辑子面。
- 通用多策略调度。

## 8. 后续候选能力

以下能力不阻塞 `1.0.0`：

- 每个 Role 的单 Region 数量上限与空间均衡稀疏。
- 小面、极窄面的显式结构化诊断。
- 当至少三种局部 Pattern 需要跨策略组合时，重新评估 Core 调度层。
