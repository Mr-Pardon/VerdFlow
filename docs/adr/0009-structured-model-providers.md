# ADR-0009：结构化模型与本机密钥

状态：Accepted。适用版本：1.0.0。

## 背景

模型可辅助理解和生成候选，但不应成为几何事实、任务状态或输出结果的不可验证来源。
供应商模型列表变化也不应要求发布新版 Studio。

## 决策

- 模型 Provider 只产生结构化候选；人工确认后仍由确定性用例处理几何、策略与输出。
- 内置服务模板描述协议与连接方式，不硬编码一个长期有效的默认模型。
- 支持时可读取供应商可用模型列表，最终选择由用户显式确认；发现失败仍允许合法手填。
- 实际任务冻结精确 Provider 配置、模型和策略，不因机器设置变化而改写已开始任务。
- 密钥由本机 SecretStore 保存，不进入 Profile、Catalog、项目快照或交换包。
- Local API、桌面管理令牌、供应商密钥分别授权；Renderer 不获得桌面管理凭据。
- 费用可能已发生而结果未收到的调用，不应由传输重试隐式触发第二次计费请求。

## 影响与限制

可用模型列表不保证模型支持所需结构化能力。供应商授权、费用和数据处理规则由用户
另行确认；网络服务调用不属于纯离线保证。通用 Agent、训练会话及自动执行不能因
存在模型 Provider 就绕过新契约、信任和确认流程。

## 验证要求

使用合成服务检查发现与手填、结构化校验、确认门禁、冻结配置、密钥引用及错误重试。
测试和文档仅用占位凭据，不公开账户信息、真实响应或用户数据。
