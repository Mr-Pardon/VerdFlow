# ADR-0012：桌面壳与稳定用户数据目录

状态：Accepted。适用版本：1.0.0。

## 背景

桌面交付需要文件对话框、本地服务和外部程序启动能力，但 Renderer 不应绑定某个壳。
更新程序也不应要求用户反复复制资产库和项目索引。

## 决策

- Studio 通过受控 PlatformBridge 使用桌面能力，Renderer 不直接导入 Electron 或访问磁盘。
- 当前 Windows x64 便携方式由 Electron 主进程托管 Python sidecar 与运行资源。
- IPC 只提供明确能力，校验路径和 loopback API 范围，不成为任意文件/网络命令代理。
- 打包版可变数据默认保存于 `%LOCALAPPDATA%\VerdFlow`，不放在程序包根目录。
- 开发运行目录与正式用户数据分开；显式指定的数据目录不得当临时开发目录自动删除。
- 下载和打包依赖使用固定来源、版本与校验，制品记录产品版本和源码身份。
- 桌面图标、标题栏和系统窗口控件归壳层，不进入 Core、策略或领域契约。

## 影响与限制

Windows 免安装更新遵循 [ADR-0015](0015-portable-application-updates.md)，
需构建时配置发布来源；未提供安装器、代码签名或跨平台发布支持。
数据路径稳定不代表任意数据库版本可回退；迁移和备份需要独立验证。
外部 Blender/DTS 安装、授权和兼容条件不因打包而消失，也不随产品源码许可开放。

## 验证要求

测试受控 IPC、路径逃逸、服务启动/退出、端口与实例复用、空白数据启动及稳定数据目录。
发布制品检查无私人项目、凭据和缓存；可见窗口与原生对话框在真实桌面环境验收。
