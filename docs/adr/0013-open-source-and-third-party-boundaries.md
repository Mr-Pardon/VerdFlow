# ADR-0013：开源许可与第三方边界

状态：Accepted。适用版本：1.0.0。

## 背景

VerdFlow 希望降低使用和扩展门槛。源码、第三方组件、扩展包、模型数据及品牌需要明确
各自的授权范围，而不是混为一个笼统声明。

## 决策

- VerdFlow 自有源码采用 Apache-2.0，允许遵守协议的商业使用、修改和再分发。
- 项目发起人与初始架构设计者署名为 Mr_Pardon；后续贡献按实际工作记录，不将第三方
  作品归入原作者名下。版权与来源声明见项目的 NOTICE 和 AUTHORS.md。
- 第三方组件保留原有许可与必要声明，项目许可不重新授权平台 SDK、模型、贴图或商标。
- 不分发 Blender 或 DTS 的程序及 SDK；用户自行安装并确认对应运行环境的使用条件。
- Blender API 脚本与外部 Supervisor 分开识别；与外部软件组合或分发时按实际构成
  核对兼容性，不能仅凭进程边界认定没有许可义务。
- 测试所需的资产索引不附带模型，不代表面向用户的资源库，也不保证目标平台拥有相应模型。
- 用户输入与业务输出的权利由其内容和来源决定，不因被软件处理就自动取得再分发授权。

## 影响

源码、扩展包和可执行制品分别维护其依赖与许可说明。商业部署仍需遵守所使用的平台、
模型和服务条款；开源许可不是对全部运行环境的权利保证。
