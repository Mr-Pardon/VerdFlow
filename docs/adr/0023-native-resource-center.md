# ADR-0023: 内嵌资源预览与只读策略更新发现

- 状态：Accepted。随 1.1.0 交付。
- 日期：2026-11-03
- 关联：ADR-0004、ADR-0018、ADR-0020

## 背景

用户需要在 Studio 内浏览资产、策略和种植方案，查看说明与版本记录后导入。
策略库也需要发现资源中心的新版本，但不能形成另一条替换、信任或方案迁移链路。

## 决策

1. Studio 使用原生列表与详情页，不内嵌远程站点脚本。SystemHost 负责受限的目录读取、
   缓存和本地库存比对；Local API 仅提供经过管理鉴权的传输。Core、LibraryStore 和
   策略包不增加联网职责。
2. 目录、Markdown、封面和关联资源只用于展示。可导入版本必须与已审核 import-index
   的身份、版本、包摘要和大小相符。预检重新读取清单并检查 revision，不信任客户端 URL。
3. 单资源导入复用既有预检、确认、依赖补齐、校验、取消和导入流程。来源资产库保持可选，
   同名内容冲突保持显式处理。新策略版本并存，不替换旧包、不继承信任、不改写现有方案。
4. 策略库只比较已安装与已审核的稳定语义版本，并提供详情入口。较高 major 单独提示，
   不承诺自动兼容；不自动下载、不自动切换，不另建策略更新器。
5. Markdown 禁用原始 HTML，图片只来自固定资源源的版本化位图路径。外链遵循桌面壳
   白名单；PAK 保持外部链接，应用不下载、执行或安装 PAK。
6. 缓存有时限与容量上限，不保存成项目事实。网络异常不影响本地资源使用；可用缓存
   带明确提示，导入必须重新预检。页面退出忽略迟到响应，关闭导入沿用已有取消协议。

## 影响

新增资源中心的只读查询与单项选择入口，不改变资源包、种植链路或策略信任契约。
版本判断、下载和导入仍有单一所有者；资源中心展示版本不冒充本地资产库的发行版本。
目录解析、版本比较、鉴权、清单变化、冲突、取消、Markdown 安全及响应清理需要回归覆盖。
