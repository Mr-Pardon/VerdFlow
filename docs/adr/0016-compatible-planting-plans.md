# ADR-0016：策略语义版本与方案兼容

状态：Accepted。适用版本：1.0.0。补充 [ADR-0004](0004-strategy-contract-and-trust.md)、
[ADR-0006](0006-planting-plans-and-execution.md) 和 [ADR-0011](0011-package-exchange-and-authoring.md)。

## 背景

方案每次随策略升级重新配置会增加使用成本。使用策略版本号表达兼容承诺，不增加另一套
兼容版本清单；结构可读取与构图语义兼容必须区别对待。

## 决策

- 新策略包遵循 SemVer，策略与包版本一致。自动选择仅适用于同一策略 ID、同一 major、
  major >= 1 且严格更高的正式版本。`0.x`、预发布和旧非规范版本只精确匹配；build metadata
  不建立升级关系。精确版本仍可参与校验，不自动降级或跨 major。
- patch 用于兼容修复，minor 用于兼容扩展。角色含义、开关行为、构图关系、参数键、单位
  或数值语义的破坏性修改必须升 major；新增可选角色对旧方案默认关闭，新参数有兼容默认值。
- SystemHost 选择已安装、已信任且通过角色与参数校验的最新兼容包；不自动下载或继承信任。
  Studio/WebUI 只消费解析结果，不维护各自版本规则。不存在可用版本时明确返回原因。
- Profile 保存版本仍是基线，查询返回解析版本、hash 和问题，不写回 generation 或内容。
  显式保存或复制才更新基线，并保留乐观并发校验。未知角色和参数不静默删除，越界值不截断。
- 任务提交冻结原始方案快照、实际执行的精确版本/hash 和补齐后的参数；分配、重试和恢复
  使用该快照，不随 Library 变化。来源 hash 与实际执行策略身份分别记录。
- `.vfp` 格式不变。同版本不同 hash 不能冒充原依赖；更高兼容版本通过解析和信任校验后
  可使用。导出基于可用版本建立临时交换快照，不修改本地方案。
- VFS Author 的 `--previous` 检查删除角色/参数、收窄范围、必填角色及显式关系等结构变化，
  拒绝明显的同 major 破坏性改动。不执行生成器，不声称证明算法语义兼容。

## 影响与限制

版本号是作者承诺，不是语义证明。自动兼容不保证新旧结果逐点相同；精确复现依赖原包、
固定 seed、参数和运行快照。策略作者仍需维护语义与回归测试。

## 验证要求

覆盖数字版本排序、预发布和 `0.x`、禁止跨 major/降级、信任撤销、结构校验、纯查询不写回、
新增可选角色关闭、方案修改不影响活动任务，以及 Author Kit 独立离线检查。
