# ADR-0017：首次使用引导与本机进度

状态：Accepted。适用版本：1.0.0。

## 背景

首次使用需要认识资源、外部环境和工作入口，但引导不能成为另一套资源管理器，也不能
以“看过介绍”替代实际可用性检查。

## 决策

- 引导只属于 Studio 的 `features/onboarding`。页面注册真实状态和已有动作，不增加
  Core API，不进入策略或资源包格式，不根据完成进度绕过执行校验。
- 顺序为资产库、策略库、运行环境、可选模型服务、DTS 工作台、项目与可选种植方案。
  欢迎页后使用非模态提示，可收起、暂停、跳过，从设置继续或重新开始。
- VFA Author / VFS Author 是可选的 Agent 创作资料包，不是可导入资源包，普通种植不依赖 Agent。
- 不假设随包目录、包名或数量，不自动导入、信任或启动任务。用户操作复用页面动作；
  批量信任仍保留二次确认和撤销规则。环境按实时、FBX 或两种路线分别检查。
- 首次自动提示仅在项目首页、服务读取成功且没有现有配置时出现；升级不打断已有用户，
  读取失败不当作新用户。介绍工作台入口时不自动进入内部工作流。
- 版本化本机 UI 偏好只保存步骤、已浏览/跳过及路线偏好，不保存路径、密钥、包内容或
  “已就绪”结论。重启仅提供继续入口，不自动跳页；存储不可用时降级为当前会话。
- 页面卸载解除注册，壳层卸载清理作用域并使迟到读取失效，不增加后台轮询。

## 影响与限制

没有随包资源仍可了解产品。引导完成不表示已具备种植条件；后续若增加随包快捷导入，
需独立评估路径、权限和包信任边界。

## 验证要求

覆盖空安装与已有配置、读取失败、迟到响应、注册清理、锁定动作、暂停恢复、路线分支及
Author 说明；使用隔离平台替身检查导航、导入取消、信任确认和不同视口布局。
