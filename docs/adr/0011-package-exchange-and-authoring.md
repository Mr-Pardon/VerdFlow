# ADR-0011：包交换与 Author 工具包

状态：Accepted。适用版本：1.0.0。

## 背景

用户需要交换策略、资产索引和种植方案，也需要把契约交给外部创作工具。
作者工作区、交换快照、库内可变对象和执行信任必须保持不同语义。

## 决策

- `.vfs` 交换精确策略包，`.vfa` 交换 Catalog 及支持的引用资源，`.vfp` 交换自包含 Profile。
- 文件格式只表达各自契约；不把普通工具资料 ZIP 当作可执行策略或资产交换包。
- 导出使用确定性顺序与元数据，写完回读验证身份；导入验证路径、条目、声明闭包和体积。
- 拒绝路径逃逸、非法链接、加密和重复项等不安全归档，不根据文件后缀推断可信度。
- 导入 `.vfs` 不自动信任；信任精确内容与发布者身份验证是不同能力。
- Profile 携带执行所需目标引用，来源库和图片可选；不承诺 `.vfp` 嵌入全部缩略图。
- VFS/VFA Author 是只读模板和规则，由独立资料包维护，随契约更新并接受一致性测试。
- 外部创作结果通过标准包、人工审阅和显式入库进入产品，不允许绕过用例写 Library。
- `.vfp` 保留原始精确依赖，接收端可按 [ADR-0016](0016-compatible-planting-plans.md)
  解析更高兼容版本；导出基于实际可用版本生成交换快照，不改写本地方案。
- VFS Author 可离线比较前后包的结构兼容性，不运行生成器，也不代替作者判断算法语义。

## 影响与限制

校验和不能证明作者身份或代码安全。本版本不承诺签名分发、安全沙箱或自动理解任意
资产文档。包中可能包含模型定位、名称、图片和来源信息；“可移植”不等于“可公开”。
第三方资产和扩展包仍应有各自清楚的权利与依赖说明。

## 验证要求

测试字节稳定、往返身份、归档攻击输入、未信任执行拒绝、来源缺失与可选资源回退。
公共测试使用合成资源，不附带需要用户授权的模型或业务搭配。
