# ADR-0025：实时 SHP 会话草稿与长任务

状态：Accepted。取代 [ADR-0021](0021-bounded-live-geospatial-input.md) 的实时 SHP 累计规模门槛。

## 决策

- 实时入口与工作台共用按要素 SHP 读取及拓扑验证。完整几何写入宿主会话的私有草稿；
  所有要素通过验证后才发布引用。不自动切面、填洞、修复拓扑或转换坐标。
- WebUI 按完整面分批提交坐标给场景，然后维护对象 ID 和选区元数据。显隐复用原对象；
  种植和导出提交会话内引用，执行使用精确几何。手绘内联请求、认证、压缩包与磁盘保护仍适用。
- 大点集按空间窗口分批传输射线，单面采样失败不废弃其余有效面。传输批次不限制任务总量；
  单个复杂面、场景对象和原生导入仍受实际机器资源约束。
- 后台任务从排队到结束持有会话租约，结束后重新计算空闲期限。只交付一份 XML，同一导入
  命令只可领取一次。导入中不提供取消等待，不因 WebUI 无响应推断完成或失败，也不自动重放。

## 验证边界

自动测试验证选区、Core 和回执协议；原生绘制与导入吞吐需在真实 Explorer 场景测量。
