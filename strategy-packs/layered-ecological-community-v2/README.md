# 层次生态群落 2.2.2

2.2.2 优化密度场计算：使用最多 65,536 个单元的 LRU 缓存复用噪波内部格点，将每个
Region 的覆盖率阈值统计网格预算从约 24,000 降至约 2,048。缓存计算与旧噪波值精确一致；
统计预算调整可能改变少量支撑区边缘点，不承诺与 2.2.1 逐点相同。共享宏观场、微观扰动、
角色关系、纹理分辨率、候选网格、间距和旋转规则保持不变。

仅使用 Python 标准库，沿用 Strategy API v1、既有参数和 PointSet v2；无需更新 Core。
包内固定参数示例继续保留。旧包和已有 Profile 不自动迁移。

该版本将空间职责压缩为两个 Role，并采用可复用的共享宏观密度纹理加角色微观扰动：

- `groundcover_matrix`：铺底植被。
- `focal_structure`：主景植被。

启用铺底时，主景支撑区是地表支撑区的高值子集；关闭铺底时，主景覆盖比例直接以完整
Region 为基准。Profile 仍可为每个 Role 映射多个资产，并通过权重
随机分配具体实例；策略包只负责目标无关的空间点位。

策略根据 `excluded_role_keys` 决定构图，关闭角色会跳过其专属计算。关闭铺底后主景可能
重新分布，因此不声明 `filter_equivalent`；固定区域、参数、种子和角色开关仍可复现。
Core 始终执行角色过滤兜底，不参与策略内部的构图判断。见 ADR-0004。

公开参数均使用百分比和米：

- 地表支撑覆盖率。
- 主景覆盖比例。
- 地表植被间距。
- 主景植被间距。
- 宏观斑块尺度。

关闭铺底时隐藏其覆盖率与间距，生成器内部将有效支撑范围视为 100%；原始参数仍保存
在草稿、Profile 与执行命令中，重新启用后恢复。这里的比例描述支撑面积，不是资产冠幅。

Profile 按策略精确版本绑定，本版本需新建或加载绑定 `2.2.2` 的 Profile。旧策略包、
Profile、批次和 XML 不会自动更新。

本版本沿用 2.2.0 的单角色构图语义。在 `strategy.yaml` 的
`extensions.role_presentation` 中携带用途分组、搭配建议与构图示意。
展示资料随 `.vfs` 分发，应用只通用渲染。
新包需按精确 hash 重新导入和信任，不替换已有项目冻结的策略或自动更新 Profile。
