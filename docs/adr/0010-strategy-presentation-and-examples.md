# ADR-0010：策略展示与参数示例

状态：Accepted。适用版本：1.0.0。

## 背景

角色说明和参数例图能降低理解门槛，但不能让 Studio 为每个策略维护专属资料或算法。
示意也不应被误认为正式项目结果。

## 决策

- 角色名称、分组、用途建议、示意几何和参数关联由策略包可选声明。
- App 通用渲染声明，不按策略 ID 或参数键建立私有资料表，不加载策略自带任意界面脚本。
- 参数示例使用策略包持有的单一合成样本与固定示例种子，按策略用途设计样本形状。
- Core 使用独立示例用例校验权限和输入，Worker 调用原生成器，不要求另写近似算法。
- 示例是有预算的临时展示投影，不建立正式项目、点集或输出，不进入高程与导出链路。
- 角色关闭规则仍由原生成器决定；示例超限、缺失或失败不阻断正式种植。
- 参考范围由 App 结合搭配快照、可选半径和通用候选/缩放解析绘制，不传回策略。
- 更换植被、权重或缩放只重做搭配解析/绘制，半径和图例变化只重绘，不重跑空间算法。
- Studio 和 WebUI 共用应用层展示组件；各自的客户端、侧板和授权仍由各 App/Connector 持有。
- 关闭页面、替换输入或收起示例时取消请求，丢弃迟到结果并释放进程、观察器和绘制资源。

## 影响与限制

参考圆不是实际冠幅、碰撞或覆盖率保证；没有尺寸数据时保留角色点表示。
示例不会替用户验证真实区域规模与性能。通用短暂缓存不等于策略增量计算承诺，
策略作者不需要理解资产库、桌面壳或预览控制器。

## 验证要求

检查包声明、原生成器一致性、角色和参数、输入合并、缓存复用、迟到响应、关闭清理、
缺失半径回退，以及不同面板尺寸和 DPI 下的可见画布。
