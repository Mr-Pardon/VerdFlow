# ADR-0007：实时多面采样与场景交付

状态：Accepted。适用版本：1.0.0。

## 背景

实时输入需要让多块区域共享执行链路，减少重复相机移动，并避免单个区域的采样错误
使全部有效结果丢失。目标平台导入可能阻塞，不能把短暂未回执误报为失败。

## 决策

- Connector 持有会话与有界命令、关联标识和授权；不开放任意 SDK 命令或 XML 路径代理。
- 绘制和文件导入形成同一种规范选区草稿，贴地预览归当前会话所有，描边与定位范围
  随实际选区调整，不将整个采样网格或射线高度当作相机范围。
- SDK 边界按空间窗口组织射线并共享相机定位；传回结果使用冻结点位索引，不改变
  原始 Region 边界、策略构图或点位顺序。
- 可重试的单面采样错误在有限重试后隔离，继续其他区域；认证、会话和整体传输错误
  不伪装成局部几何错误。失败面不输出部分残缺结果，也不静默按零高程成功处理。
- 至少有成功点时生成成功结果并报告失败清单；全部失败不生成伪成功 XML。
- 采样前记录相机，结束时尝试平滑恢复。相机和原生回调逻辑留在 SDK/App，不进入策略。
- 导入完成必须依据本次调用业务结果或匹配当前输出路径的回执，排除旧消息和派发确认。
- 慢导入提示后继续等待真实回执；取消释放本页等待，不保证撤销已经开始的原生导入。
- 点位和高程在进入 Core 时完整验收；已登记不可变输出路径保留必要一致性和数值检查，
  不对大文档反复执行同一全量校验，也不提供客户端通用“跳过校验”开关。

## 影响与限制

贴地面可能无法被场景直接拾取；通过点击 XY 与本会话可见选区做界面命中，不修改
执行选择。空间窗口不是自动种植分批、几何合并、地形加载检测或持久断点续传。
原生导入仍可能使目标应用暂时无响应，用户取消后应检查场景，避免重复导入。

## 验证要求

测试混合成功、全部失败、重复及冲突采样块、旧回调、长等待、取消与销毁清理。
合成 SDK 测试不能代替目标平台现场导入和相机行为的验收。
